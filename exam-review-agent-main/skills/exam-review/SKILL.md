# 复习卷生成流程

## 第 1 步：确认范围
- 从用户的话里确定科目和章节（如"数据结构·树与二叉树"）。
- 用户没说范围时，默认覆盖全部笔记，不要反复追问。

## 第 2 步：检索笔记
- 先用 `search_notes` 按章节关键词检索，找到相关的笔记文件。
- 再用 `read_note` 读取相关笔记的**全文**。出题必须基于全文，不能只看检索片段。

## 第 3 步：按固定结构出卷
复习卷正文使用 Markdown，按以下结构组织（题量以用户要求为准，没有要求时用默认值）：

```
## 一、核心知识点
（5~8 条，每条一句话，带上时间复杂度等关键结论）

## 二、选择题（默认 5 道）
1. 题干
   A. … B. … C. … D. …

## 三、简答题（默认 3 道）

## 四、综合题（默认 1 道，如手算过程、画图、写代码）

## 五、笔记疑问解答
（针对笔记中「我的疑问」小节，挑 1~3 个给出解答）

## 六、答案与解析
（每题给出答案、简要解析，并注明出处，如「出处：02_树与二叉树.md」）
```

## 出题规则
- **只考笔记里出现过的内容**。笔记没写的知识点（例如笔记明确说"还没讲""下节课讲"的内容）不出题。
- 选择题的干扰项要有迷惑性，优先考笔记里标了"易错""⚠""必考"的地方。
- 如果笔记中有自相矛盾或可能错误的地方，在解析里指出。
- 题目和答案分开：前五部分不出现答案。

## 第 4 步：导出
- 调用 `save_review_sheet`，title 写成"科目·章节 复习卷"，markdown_content 填完整正文。
- 导出后，在回复中告诉用户文件路径，并简要说明卷子的结构和覆盖的知识点，不要在回复里把整份卷子再贴一遍。
