## 1. 基本概念

- 图 G = (V, E)，V 顶点集（不能为空），E 边集（可以为空）
- 有向图 / 无向图；有向图的边叫"弧"，<v, w> 表示 v → w
- 完全图：无向完全图有 n(n-1)/2 条边，有向完全图有 n(n-1) 条弧
- 度：
  - 无向图：**所有顶点度之和 = 2 × 边数**
  - 有向图：入度、出度，入度之和 = 出度之和 = 弧数
- 连通图（无向）、强连通图（有向）
  - n 个顶点的无向图要连通，至少 n-1 条边
  - 连通分量 = 极大连通子图
- 生成树：包含全部顶点的极小连通子图，n 个顶点 n-1 条边

## 2. 存储结构

### 邻接矩阵

```c
#define MaxV 100
typedef struct {
    char vex[MaxV];          // 顶点表
    int  edge[MaxV][MaxV];   // 邻接矩阵，带权图存权值，无边存 ∞
    int  vexnum, arcnum;
} MGraph;
```

- 无向图的矩阵是**对称**的，可以只存上三角（压缩存储）
- 第 i 行非零元素个数 = 顶点 i 的度（有向图是出度）
- 空间 **O(n²)**，适合**稠密图**
- 判断两点之间有没有边 O(1)，但找某个点的所有邻接点要 O(n)

### 邻接表

- 每个顶点一个单链表，存它的邻接点
- 空间：无向图 O(n + 2e)，有向图 O(n + e) → 适合**稀疏图**
- 找邻接点快，但判断 (i, j) 有没有边要遍历链表
- 邻接表**不唯一**（链表里结点顺序可以不同），邻接矩阵是唯一的

```c
typedef struct ArcNode {        // 边表结点
    int adjvex;                 // 邻接点下标
    struct ArcNode *next;
} ArcNode;

typedef struct VNode {          // 顶点表结点
    char data;
    ArcNode *first;
} VNode, AdjList[MaxV];
```

其他：十字链表（有向图）、邻接多重表（无向图）——我只记了名字，先知道有这两种

## 3. 图的遍历

### BFS 广度优先

类似树的层次遍历，用**队列**，要有 visited[] 数组防止重复访问

```c
void BFS(Graph G, int v) {
    visit(v); visited[v] = 1;
    EnQueue(Q, v);
    while (!IsEmpty(Q)) {
        DeQueue(Q, v);
        for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
            if (!visited[w]) {
                visit(w); visited[w] = 1;   // 入队前就标记！
                EnQueue(Q, w);
            }
    }
}
```

- 邻接矩阵：O(n²)；邻接表：**O(n + e)**
- 无权图的单源最短路径可以直接用 BFS 求（按层扩展，层数就是距离）
- 非连通图要对每个没访问过的顶点都调一次 BFS，调用次数 = 连通分量数

### DFS 深度优先

类似树的先序遍历，递归（本质是用栈）

```c
void DFS(Graph G, int v) {
    visit(v); visited[v] = 1;
    for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w]) DFS(G, w);
}
```

- 时间复杂度和 BFS 一样：邻接矩阵 O(n²)，邻接表 O(n + e)
- 空间 O(n)（递归栈）
- 同一个图，存储结构确定后，邻接矩阵的遍历序列唯一；邻接表的不唯一

## 4. 最短路径

### Dijkstra（单源，边权非负）

思路：每轮从还没确定的顶点里选 dist 最小的，标记为已确定，然后用它去更新其他点的 dist（"松弛"）

- dist[]：源点到各点当前最短距离
- path[]：前驱，用来还原路径
- final[]：是否已确定

时间复杂度 **O(n²)**（每轮扫一遍找最小，共 n 轮）

⚠ **不能处理负权边**！原因：选过的点不会再更新，负边会让之前"确定"的结果变错

做题时画表格，每一轮写出 dist 和 path，考试大概率考手算过程。

### Floyd（所有顶点对）

三重循环，k 在**最外层**（这个顺序不能错）：

```c
for (k = 0; k < n; k++)
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            if (A[i][k] + A[k][j] < A[i][j]) {
                A[i][j] = A[i][k] + A[k][j];
                path[i][j] = k;
            }
```

- 意思是"允许经过 0..k 号顶点中转时的最短路径"
- 时间 **O(n³)**，空间 O(n²)
- 可以有负权边，但**不能有负权回路**

### 对比

| | BFS | Dijkstra | Floyd |
|---|---|---|---|
| 适用 | 无权图 | 带权，无负边 | 带权，可负边无负环 |
| 求什么 | 单源 | 单源 | 所有点对 |
| 时间 | O(n+e) | O(n²) | O(n³) |
