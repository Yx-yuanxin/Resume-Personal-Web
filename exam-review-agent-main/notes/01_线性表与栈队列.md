## 1. 线性表的定义

- 线性表：n 个**相同类型**数据元素的有限序列，n=0 时叫空表
- 除了第一个元素，每个元素有且仅有一个**直接前驱**；除了最后一个，有且仅有一个**直接后继**
- 两种存储方式：顺序存储（顺序表）、链式存储（链表）

## 2. 顺序表

用一段地址连续的存储单元依次存放，本质就是数组。

```c
#define MAXSIZE 100
typedef struct {
    int data[MAXSIZE];
    int length;      // 当前长度
} SqList;
```

- 随机访问：第 i 个元素地址 = LOC(a1) + (i-1)*sizeof(元素)，所以按下标取值 **O(1)**
- 插入：要把第 i 个及之后的元素都往后挪一位
  - 最好 O(1)（插在表尾），最坏 O(n)（插在表头），平均移动 n/2 次 → **O(n)**
- 删除：同理，平均移动 (n-1)/2 次 → **O(n)**
- 按值查找：O(n)

插入代码（注意 i 是位序，从 1 开始！）：

```c
int ListInsert(SqList *L, int i, int e) {
    if (i < 1 || i > L->length + 1) return 0;   // 位置不合法
    if (L->length >= MAXSIZE) return 0;          // 满了
    for (int j = L->length; j >= i; j--)
        L->data[j] = L->data[j - 1];             // 从后往前挪
    L->data[i - 1] = e;
    L->length++;
    return 1;
}
```

⚠ 易错：循环要**从后往前**挪，从前往后会把数据覆盖掉（我自己第一次写就写反了）

优缺点：
- 优点：随机存取快，存储密度高（不用存指针）
- 缺点：插入删除要移动大量元素；容量要预先分配，不好扩充

## 3. 单链表

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

- 一般带**头结点**，好处：第一个位置的插入删除和其他位置统一，不用特判；空表和非空表处理也统一
- 按序号查找 O(n)，不能随机访问
- 插入/删除本身 O(1)，**但是**要先找到前驱结点，找前驱是 O(n)
- 头插法建表：得到的顺序和输入顺序**相反**；尾插法：顺序相同（要多一个尾指针 r）

在 p 结点后面插入 s（顺序不能反！）：

```c
s->next = p->next;
p->next = s;
```

如果先写 `p->next = s;` 原来 p 后面那段就丢了。

删除 p 的后继 q：

```c
q = p->next;
p->next = q->next;
free(q);
```

### 其他链表（简单提了一下）
- 双链表：多一个 prior 指针，可以 O(1) 找前驱，插入时要改 4 个指针
- 循环链表：尾结点 next 指向头结点，判空条件变成 `L->next == L`
- 静态链表：用数组模拟，next 存的是下标（游标）——感觉考的概率不大

### 顺序表 vs 链表 对比（自己整理的，感觉适合出简答）

| | 顺序表 | 链表 |
|---|---|---|
| 存取方式 | 随机存取 | 顺序存取 |
| 按位查找 | O(1) | O(n) |
| 插入删除 | O(n)，要移动元素 | O(1)（已知位置时） |
| 空间 | 预分配，可能浪费或溢出 | 按需分配，但要额外存指针 |

## 4. 栈

- **后进先出 LIFO**，只能在栈顶插入删除
- 顺序栈：top 指针，我这里用 top 初始 = -1 的写法（也有 top=0 的写法，做题注意看题目约定！）
  - 栈空：top == -1；栈满：top == MAXSIZE-1
- 进栈出栈都是 **O(1)**

```c
int Push(SqStack *S, int x) {
    if (S->top == MAXSIZE - 1) return 0;  // 栈满
    S->data[++S->top] = x;                // 先加再放
    return 1;
}
```

- 出栈序列问题：n 个不同元素进栈，出栈序列的个数是**卡特兰数** C(2n,n)/(n+1)
  - n=3 时是 5 种，(c,a,b) 是不可能的
- 共享栈：两个栈共用一个数组，栈底在两端，top0+1 == top1 时满

### 栈的应用
1. 括号匹配：遇左括号进栈，遇右括号出栈比较
2. 表达式求值：中缀转后缀（操作符栈），后缀表达式求值（操作数栈）
   - 例：中缀 `a+b*c` → 后缀 `abc*+`
3. 递归：函数调用栈，递归太深会栈溢出

## 5. 队列

- **先进先出 FIFO**，队尾入、队头出
- 顺序队列有"假溢出"问题 → 用**循环队列**

循环队列（牺牲一个单元来区分空和满）：
- 队空：`Q.front == Q.rear`
- 队满：`(Q.rear + 1) % MAXSIZE == Q.front`
- 元素个数：`(Q.rear - Q.front + MAXSIZE) % MAXSIZE`
- 入队：`Q.rear = (Q.rear + 1) % MAXSIZE`

入队出队都是 **O(1)**。

- 链队列：带头结点的单链表，front 指头结点，rear 指尾结点
- 双端队列：两端都可以进出（输入受限 / 输出受限），考选择题

队列应用：层次遍历（树那章会用）、BFS、操作系统里的进程调度
