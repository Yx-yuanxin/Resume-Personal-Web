## 1. 树的基本概念

- 树是 n 个结点的有限集，n=0 为空树；有且仅有一个**根**
- 几个术语（容易混）：
  - 结点的**度**：孩子的个数；树的度：所有结点度的最大值
  - **叶子**：度为 0 的结点
  - 深度/高度：这里约定根在第 1 层（也有从 0 开始算的约定，做题看清楚）
- 重要性质：**结点数 = 总度数 + 1**（因为除根以外每个结点都有一条边连到父亲）

## 2. 二叉树

- 每个结点最多两棵子树，**有左右之分**（和度为 2 的树不一样！度为 2 的树至少要有一个结点度为 2）
- 满二叉树：每层都满，高为 h 的有 2^h - 1 个结点
- 完全二叉树：除最后一层都满，最后一层的结点**靠左**连续排列

### 性质（背！）
1. 第 i 层最多 2^(i-1) 个结点
2. 高为 h 最多 2^h - 1 个结点
3. **n0 = n2 + 1**（叶子数 = 度为 2 的结点数 + 1）← 选择题常考
   - 推导：n = n0+n1+n2，n = n1 + 2*n2 + 1，两式相减就出来了
4. n 个结点的完全二叉树高度 = ⌊log2 n⌋ + 1
5. 完全二叉树按层编号（从 1 开始），结点 i 的左孩子 2i，右孩子 2i+1，父亲 ⌊i/2⌋

### 存储
- 顺序存储：适合完全二叉树，普通二叉树会浪费很多空间（要补空结点）
- 链式存储（二叉链表）：

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

n 个结点的二叉链表有 **n+1 个空指针域**（2n 个指针，n-1 条边）→ 线索二叉树就是利用这些空指针

## 3. 遍历（重点！！）

三种深度优先的遍历，区别只是"访问根"的时机：
- 先序：根 左 右
- 中序：左 根 右
- 后序：左 右 根

```c
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);          // 挪到第一行就是先序，挪到最后就是后序
        InOrder(T->rchild);
    }
}
```

- 时间 O(n)，每个结点访问一次
- 空间 O(h)，h 是树高，递归栈的深度；最坏退化成链 O(n)

非递归中序（用栈）：一路往左走并压栈，走到空就弹栈访问，然后转向右子树

```c
void InOrder2(BiTree T) {
    BiTree stack[100]; int top = -1;
    BiTree p = T;
    while (p || top != -1) {
        if (p) { stack[++top] = p; p = p->lchild; }
        else  { p = stack[top--]; visit(p); p = p->rchild; }
    }
}
```

### 层次遍历
用**队列**：根入队 → 出队访问，把左右孩子入队 → 重复直到队空。O(n)

### 由遍历序列构造二叉树
- **先序 + 中序** 或 **后序 + 中序** 可以唯一确定
- 先序 + 后序 **不能**唯一确定（容易记混，标一下）
- 方法：先序第一个（或后序最后一个）是根，到中序里找到根，左边是左子树，右边是右子树，递归

例：先序 ABDECF，中序 DBEAFC
→ 根 A，左子树中序 DBE，右子树中序 FC → ……（后面自己在草稿纸上画完了）

## 5. 二叉排序树 BST

定义：左子树所有结点 < 根 < 右子树所有结点，左右子树也都是 BST
→ **中序遍历得到递增序列**（判断是不是 BST 可以用这个）

查找：

```c
BiTree BST_Search(BiTree T, int key) {
    while (T != NULL && key != T->data) {
        if (key < T->data) T = T->lchild;
        else T = T->rchild;
    }
    return T;
}
```

- 插入：查找失败的位置就是插入位置，新结点一定是**叶子**
- 删除（三种情况）：
  1. 叶子：直接删
  2. 只有一棵子树：让子树顶替它的位置
  3. 左右都有：用**中序后继**（右子树最小的，即右子树最左下）或中序前驱替换，再删掉那个后继
- 效率：查找长度和树高有关
  - 平衡时 O(log n)
  - 最坏：按有序序列插入会退化成单链 → **O(n)**
  - 所以有了平衡二叉树 AVL（左右子树高度差不超过 1），下节课讲

### ASL（平均查找长度）
ASL成功 = Σ(每层结点数 × 层数) / n
例：一棵 7 个结点的 BST，第 1~4 层分别有 1、2、3、1 个结点
ASL成功 = (1*1 + 2*2 + 3*3 + 4*1)/7 = 18/7
